## 关键发现
- Firecrawl credits 已耗尽，需降级使用 curl + 东方财富 API
- 东方财富 datacenter API 的 reportName 必须是 `RPT_F10_FINANCE_MAINFINADATA`，其他名称返回 9501 错误
- 字段名必须用大写，小写也返回 9501
- 用 `columns=ALL` 可以查看所有可用字段
